# Антикварна Лавка - Професійний Веб-додаток

Це повноцінний веб-додаток для антикварного магазину, що включає клієнтську частину для покупців та адміністративну панель для керування магазином. Проект повністю контейнеризований за допомогою Docker для легкого запуску та розгортання.

## ✨ Основні можливості

### Клієнтська частина:
- **Каталог товарів:** Перегляд антикварних товарів з фото, описом, ціною та роком створення.
- **Пошук та фільтрація:** Динамічний пошук за назвою та фільтрація за категоріями.
- **Кошик:** Можливість додавати товари в кошик та оформлювати замовлення.
- **Особистий кабінет:** Перегляд історії замовлень та їх статусів.
- **Заявки на ремонт/оцінку:** Створення та відстеження заявок.
- **Адаптивний дизайн:** Сайт чудово виглядає на будь-яких пристроях.

### Адміністративна панель:
- **Керування товарами:** Повний CRUD (створення, читання, оновлення, видалення) для товарів.
- **Обробка замовлень:** Зміна статусу замовлень (в обробці, доставлено, відхилено).
- **Керування заявками:** Відповіді на заявки клієнтів та залишення коментарів.

## 🛠️ Технологічний стек

- **Бекенд:** Python, Django, Django REST Framework (DRF)
- **Фронтенд:** React, Vite, Tailwind CSS, Framer Motion
- **База даних:** SQLite (для розробки)
- **Веб-сервер:** Nginx, Gunicorn
- **Контейнеризація:** Docker, Docker Compose

## 🚀 Як запустити проект

Для запуску проекту вам потрібен лише встановлений **Docker Desktop**.

1. **Клонуйте репозиторій:**
   ```bash
   git clone https://github.com/KaRtOfAn-hacker/antique-shop.git
   cd antique-shop
   ```

2. **Запустіть проект за допомогою Docker Compose:**
   ```bash
   docker-compose up --build
   ```
   Ця команда автоматично збере всі сервіси, встановить залежності, застосує міграції бази даних та запустить проект.

3. **Відкрийте сайт:**
   - **Клієнтська частина** буде доступна за адресою: [http://localhost](http://localhost)
   - **API бекенду** буде доступне за адресою: [http://localhost:8000/api/](http://localhost:8000/api/)
